            Cómo conectar Classroom (una sola vez)

            1. Entra en console.cloud.google.com y crea un proyecto.
            2. En «APIs y servicios» activa Google Classroom API y Google Calendar API.
            3. Pantalla de consentimiento OAuth: tipo Externo y añade tu correo como usuario de prueba. Si tu centro usa Google Workspace, puede que el administrador tenga que permitir la app.
            4. Credenciales → ID de cliente de OAuth → Aplicación web. En «Orígenes autorizados» pon https://TU-USUARIO.github.io
            5. Copia el Client ID y pégalo en la línea const CLIENT_ID='' al principio del script de index.html. Solo se hace una vez; después basta con tu correo.
